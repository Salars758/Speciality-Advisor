# Speciality Консультант

Профессиональная система профориентации на основе анализа личностных качеств, интересов и профессиональных склонностей пользователя.

## Описание

Speciality Консультант — это веб-приложение для помощи в выборе будущей профессии. Система проводит интерактивное тестирование, анализирует ответы пользователя и рекомендует наиболее подходящие специальности, основываясь на современных психологических методиках и алгоритмах обработки данных.

Проект разработан как учебный информационный ресурс студентами группы ПРО-438Б Уфимского университета науки и технологий.

## ✨ Основные возможности

### Для пользователей:
*   Регистрация и авторизация
*   Прохождение адаптивного теста
*   Получение персонализированной рекомендации по специальности
*   Просмотр статистики и результатов в личном кабинете
*   Изучение описаний всех доступных специальностей

### Для администраторов и психологов:
*   Полное управление справочниками:
    *   Специальности
    *   Качества (ментальные и интеллектуальные)
    *   Тесты и вопросы
    *   Варианты ответов
    *   Требования к качествам для каждой специальности
*   Управление сессиями и результатами тестирования
*   Администрирование пользователей
*   Просмотр аналитики:
    *   Гистограммы частоты рекомендаций по специальностям
    *   Средние баллы по качествам
    *   Графики «специальность → качество» с порогами

## 🛠️ Технологический стек

### Backend:
*   **FastAPI** — современный фреймворк для создания REST API
*   **JWT** — токен-базированная аутентификация
*   **MariaDB** — реляционная СУБД с поддержкой внешних ключей
*   **SQLAlchemy ORM** — работа с базой данных
*   **Locust** — нагрузочное тестирование

### Frontend:
*   Чистый HTML, CSS, JavaScript (ES6+)
*   Адаптивная верстка
*   Интерактивные компоненты:
    *   Модальные окна
    *   Выпадающие меню
    *   Динамические формы
    *   Radar-график (Chart.js)
*   Поддержка ролевой модели (RBAC): `applicant`, `psychologist`, `admin`

### Инфраструктура:
*   Linux-виртуальная машина
*   Автоматический запуск FastAPI при старте системы

## 🔐 Безопасность и авторизация

*   JWT-токены с зашифрованным payload
*   Разграничение прав доступа по ролям
*   Защита от несанкционированного доступа к административным разделам
*   Валидация и подтверждение критических действий (удаление, выход и т.д.)

## 📊 Архитектура данных

Система оперирует следующими сущностями:

*   **Пользователи** — участники тестирования и администраторы
*   **Тесты** — наборы вопросов
*   **Вопросы** — привязаны к тесту и качеству
*   **Варианты ответов** — с баллами за каждый выбор
*   **Качества** — ментальные/интеллектуальные характеристики
*   **Специальности** — с описаниями и требованиями к качествам
*   **Сессии** — пройденные тесты
*   **Результаты** — рассчитанные уровни качеств и рекомендации

## 🚀 Запуск проекта

1.  Настройте MariaDB и примените миграции.
2.  Установите зависимости Python (FastAPI, SQLAlchemy, python-jose и др.).
3.  Запустите сервер:
    ```bash
    uvicorn main:app --reload
    ```
4.  Откройте `index.html` в браузере.

> **Примечание:** Frontend обращается к API по адресу `http://localhost:8000` при локальной разработке.
